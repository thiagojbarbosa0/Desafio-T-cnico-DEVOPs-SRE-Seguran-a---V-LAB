Resposta da API

Escolha um usuário e um curso e execute a verificação.

O que será validado?

1
Identidade

A solicitação é autenticada com um token temporário do usuário escolhido.

2
Propriedade

O backend confere se o usuário pode alterar o curso selecionado.

3
Resultado

Um usuário sem permissão deve receber HTTP 403; um proprietário autorizado pode receber 200.

Execução permitida somente em localhost. O resultado não envolve credenciais ou sistemas dos autores.
